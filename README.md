# DaoVesper

DaoVesper is a real-time, event-driven system that utilizes state-machine-based workflows for seamless, auto-scaling network management.

With DaoVesper, you get a lightweight tool that stays out of your way.

**What you get**

- DaoVesper is a real-time, event-driven
- system that utilizes state-machine-based workflows
- for seamless, auto-scaling network management

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoVesper.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
